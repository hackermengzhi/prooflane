# 阶段计划

## M0：项目与运行底座（进行中）

- [x] 独立仓库、架构、业务样例
- [x] SQLite 任务与证据登记、CLI、持久化测试
- [ ] 任务状态机、事件日志、取消与恢复
- [ ] 工具协议、环境配置与凭据脱敏

## M1：第一条完整业务链

- [ ] 本地下单演示服务与确定性的缺陷开关
- [ ] 需求导入、版本与引用；模型接入和结构化输出
- [ ] 需求审查、用例生成、HTTP 执行与结果断言
- [ ] 浏览器操作与网络请求采集
- [ ] 关联订单、支付、库存状态及服务日志
- [ ] 输出缺陷报告；修复后重跑并比较回归结果

验收：从同一需求文档出发，复现演示服务中预设的支付状态缺陷，保留可检查证据，修复后原失败用例通过。模型不可用时明确阻塞，不生成伪造结果。

## M2：多 Agent 与知识检索

- [ ] 角色协作、共享任务与证据、上下文预算
- [ ] RAG、需求变更和代码影响分析
- [ ] 回归选择、并行执行、失败重试与不稳定用例识别

## M3：环境与产品化

- [ ] OCR 与视觉补充、分布式追踪、消息与数据库适配器
- [ ] 进程隔离、worker、资源回收与崩溃恢复
- [ ] Web 工作台、CI 接入、权限与审计
- [ ] 独立评测集：缺陷检出、误报、定位质量、费用与耗时

每阶段都有可执行验收，不以 Agent 数量或生成用例数量代表质量。
