# 登录与会话接口需求

`service.py` 提供 `create_server(host="127.0.0.1", port=0, *, clock=time.monotonic)`，返回尚未启动的 `ThreadingHTTPServer`。每个实例的失败计数、锁定状态和令牌独立；`clock` 是无参数、返回秒数的可调用对象。测试可注入时钟并直接推进时间，无须等待真实过期。

演示用户：`alice` / `Alice-pass-123!`、`bob` / `Bob-pass-456!`。以下接口的响应均为 JSON。

- **S1 登录**：`POST /login`，请求体为 `{"user": "alice", "password": "Alice-pass-123!"}`。未锁定用户凭据正确时返回 200 和 `{"token": "..."}`；令牌是至少 32 个字符的随机不透明字符串，不得直接使用用户名或密码充当令牌，每次登录签发不同令牌，已有令牌继续有效。未知用户或密码错误均返回 401 和完全相同的 `{"error": "invalid credentials"}`。非法 JSON、非对象请求体、缺失字段、空字段或非字符串字段返回 400，且不计为密码错误。
- **S2 锁定**：按用户分别累计连续密码错误次数。前五次密码错误均返回 401；第五次后锁定，该用户此后的登录（包括正确密码）均返回 423 和 `{"error": "account locked"}`。成功登录将该用户失败计数清零；其他用户不受影响。锁定在本服务实例生命周期内不解除，不撤销已签发令牌。
- **S3 鉴权**：`GET /me` 必须携带精确格式的 `Authorization: Bearer <token>`，合法有效时返回 200 和 `{"user": "alice"}`（实际所属用户）；缺失、错误格式、未知或其他实例签发的令牌均返回 401 和 `{"error": "unauthorized"}`。
- **S4 过期**：每个令牌从签发时间起固定有效 60 秒，在签发时间 + 60 秒之前有效，恰好到期或超过到期时间返回 401。访问不延长有效期；不同时间签发的令牌分别计时。过期令牌不能用于 `/me` 或 `/logout`。
- **S5 登出**：`POST /logout`，请求体 `{}`，使用与 `/me` 相同的 Bearer 鉴权。有效令牌返回 200 和 `{"ok": true}`，并立即使当前令牌失效；再次登出或访问 `/me` 返回 401。其他令牌（包括同一用户的令牌）不受影响。鉴权失败返回 401 和 `{"error": "unauthorized"}`，不改变已有会话。
- **S6 密码保密**：响应体、响应头和服务日志（标准输出、标准错误）均不得包含请求中的明文密码，包括正确密码、错误密码、未知用户密码和锁定时提交的密码。
