# 运费产品备忘（零散摘录）

这不是需求全集。备忘没写到的地方，以现有代码行为为准，需要用测试锁定。
`tariff.py` 是老系统留下的纯函数计价库；接口和未记载的细节请读代码确认。

- **N1 重量**：输入重量单位为 kg，必须是有限数值，大于 0 且不超过 30。非法重量抛出 `ValueError`，不应产生报价。
- **N2 地区**：现有业务只有 `local`、`country`、`remote` 三种地区；不支持其他地区，遇到其他地区抛出 `ValueError`。
- **N3 偏远费**：`remote` 每单固定附加 450 分，会员也不能减免这笔附加费。
- **N4 会员**：会员减免基础运费的 12%，单笔减免最多 600 分；非会员不减免。附加费不参与会员折扣。
- **N5 最低收费**：每次有效报价的最终收费不得低于 500 分。
- **N6 金额**：报价明细中的 `base`、`remote`、`express`、`discount`、`minimum` 和 `total` 都是以分计的整数；`total` 是最终收费。别改成浮点元。
